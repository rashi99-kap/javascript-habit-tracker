# Habit Tracker

A Habit Tracker application built using HTML, CSS, and JavaScript.

## Features

- Add habits
- Edit habits
- Delete habits
- Mark habits as Done/Pending
- Filter habits (All, Completed, Pending)
- Save data using localStorage
- Display total, completed, and pending habit counts

## Technologies Used

- HTML
- CSS
- JavaScript

## Learning Outcomes

- DOM Manipulation
- Event Handling
- Arrays and Objects
- Local Storage
- Filtering and Rendering
